Come possiamo aiutarti?

Qui trovi le indicazioni essenziali per usare Portafogli e gestire il backup Excel.

Backup e sincronizzazione Excel

  1. Apri Impostazioni nell’app Portafogli.
  2. Seleziona la funzione di backup o sincronizzazione Excel.
  3. Scegli dove salvare il file tramite il selettore File di iOS.
  4. Puoi aprire il file dal Mac, aggiungere movimenti e poi sincronizzarlo nuovamente dall’app.

Prima di modificare il file è consigliabile conservarne una copia. Non rinominare i fogli e non eliminare le intestazioni delle colonne.

Domande frequenti

Dove sono conservati i dati?

I dati dell’app sono conservati sull’iPhone. Il file Excel viene salvato nella posizione scelta dall’utente, per esempio “Su iPhone”, iCloud Drive o un altro servizio disponibile nell’app File.

Lo sviluppatore può vedere i miei movimenti?

No. L’app non invia allo sviluppatore portafogli, saldi, budget o movimenti.

Cosa faccio prima di reinstallare l’app?

Esporta un backup Excel e verifica che sia leggibile. La rimozione dell’app può eliminare i dati memorizzati localmente.

La sincronizzazione crea movimenti duplicati?

L’app confronta i movimenti già presenti e importa soltanto quelli nuovi riconosciuti. È comunque consigliabile non modificare manualmente le colonne tecniche del file.

Contatti

Hai ancora bisogno di aiuto?

Scrivi indicando il modello di iPhone, la versione di iOS e una breve descrizione del problema. Non allegare file contenenti dati finanziari reali se non strettamente necessario.
